# ESTILO MED — SISTEMA PREMIUM G TECH 2026

Sistema estático pronto para deploy no Netlify.

## Deploy hoje
1. Descompacte este ZIP.
2. No Netlify, escolha **Add new site → Deploy manually**.
3. Arraste a pasta `ESTILO_MED_SISTEMA_GTECH_2026` inteira para a área de deploy.
4. Aguarde a publicação. Não existe build obrigatório.
5. Teste no celular: intro, vitrine, busca, produto, assistente e WhatsApp.

## Fonte de dados
- 30 itens estruturados em `data/products.json`.
- 9 Elegance e 21 Essential.
- Imagens de produtos extraídas diretamente dos PDFs enviados.
- As cores permanecem para confirmação visual/comercial; o sistema não inventa nomes de swatches.

## Assistente IA
A prévia inclui um assistente inteligente local baseado no catálogo. Ele funciona sem API e sem chave. O motor cruza palavras-chave da necessidade do cliente com características/diferenciais reais dos produtos e retorna 3 sugestões. A arquitetura pode ser conectada futuramente a um endpoint de IA, sem depender disso para funcionar agora.
